Политика конфиденциальности игры «Лопни»

Дата вступления в силу: 8 октября 2026 года

Настоящая Политика конфиденциальности описывает, какие данные могут обрабатываться мобильной игрой «Лопни», для каких целей они используются, где хранятся и каким образом пользователь может управлять своими данными.

2. Назначение приложения

«Лопни» — мобильная казуальная игра, в которой пользователь проходит игровые уровни, взаимодействует с пузырями, получает игровые результаты и открывает новые уровни.

Для использования основных функций игры регистрация и создание пользовательского аккаунта не требуются.

3. Данные, хранящиеся на устройстве

Основная игровая информация хранится локально на устройстве пользователя.

К таким данным могут относиться:

  • прогресс прохождения уровней;
  • результаты и рекорды;
  • количество полученных звёзд;
  • состояние игровых предметов;
  • сохранённое состояние текущей игровой партии;
  • настройки звука, музыки и вибрации;
  • другие локальные игровые настройки.

Эти игровые данные не используются разработчиком для создания рекламного профиля пользователя.

Удаление приложения или очистка его данных средствами операционной системы Android может привести к удалению локально сохранённого игрового прогресса и настроек.

4. Доступ к Интернету

Игра может использовать подключение к Интернету для следующих функций:

  • загрузки и показа рекламы;
  • получения удалённой конфигурации собственных рекламных материалов;
  • загрузки изображений собственных рекламных материалов;
  • получения информации о предлагаемой следующей игре;
  • открытия страницы приложения во внешнем магазине приложений.

Основной игровой процесс не требует передачи игрового прогресса разработчику.

5. Реклама

В игре используется реклама.

В частности, могут использоваться:

  • полноэкранные рекламные объявления;
  • рекламные объявления с вознаграждением, которые пользователь может просматривать добровольно для получения игрового предмета;
  • собственные рекламные или информационные материалы разработчика о других приложениях и продуктах.

Рекламные объявления отделяются от основного игрового содержимого.

6. Yandex Mobile Ads SDK

Для показа сторонней рекламы игра использует Yandex Mobile Ads SDK.

При работе рекламного SDK компания Яндекс и подключённые рекламные сервисы могут автоматически обрабатывать техническую информацию, необходимую для показа рекламы, обеспечения её работы, предотвращения злоупотреблений и оценки эффективности рекламных кампаний.

В зависимости от настроек устройства, операционной системы, разрешений пользователя и конфигурации рекламного SDK такая информация может включать:

  • рекламный идентификатор устройства;
  • технические идентификаторы;
  • сведения об устройстве и операционной системе;
  • сетевую информацию;
  • IP-адрес;
  • сведения о показах рекламы;
  • сведения о взаимодействии пользователя с рекламными объявлениями;
  • диагностические и технические данные.

Yandex Mobile Ads SDK может использовать рекламный идентификатор Android для показа более релевантной рекламы, если такой доступ разрешён системой и настройками пользователя.

Пользователь может ограничить персонализацию рекламы или изменить настройки рекламного идентификатора средствами операционной системы Android.

Игра самостоятельно не передаёт Yandex Mobile Ads SDK точное местоположение пользователя.

Информация о Yandex Mobile Ads SDK: документация Yandex Mobile Ads SDK .

7. Рекламный идентификатор

Yandex Mobile Ads SDK может использовать рекламный идентификатор Android (Advertising ID) для показа рекламы и измерения её эффективности.

Возможность использования такого идентификатора зависит от версии Android, настроек устройства и выбора пользователя.

Пользователь может сбросить рекламный идентификатор, ограничить его использование или изменить настройки персонализации рекламы средствами операционной системы.

8. Геолокация

Игра «Лопни» не запрашивает у пользователя разрешение на доступ к точному местоположению для игрового процесса.

Разработчик не передаёт Yandex Mobile Ads SDK координаты пользователя через настройки приложения.

9. Собственные рекламные материалы

Помимо сторонней рекламы, игра может показывать собственные рекламные или информационные материалы разработчика.

Такие материалы могут содержать:

  • название приложения;
  • логотип;
  • описание;
  • фоновые изображения;
  • скриншоты;
  • ссылку на страницу приложения в магазине приложений.

Конфигурация таких материалов может загружаться с удалённого сервера или публичного хранилища.

Собственная рекламная система разработчика не использует рекламные идентификаторы и не создаёт профиль поведения пользователя.

10. Предложение следующей игры

После прохождения последнего доступного уровня игра может показать пользователю информацию о другой игре или приложении разработчика.

Такой экран может содержать карусель изображений, описание, логотип и кнопку перехода на страницу соответствующего приложения.

Актуальные материалы и ссылка могут изменяться удалённо без обновления установленной версии игры.

Переход во внешний магазин приложений выполняется только после действия пользователя.

11. Передача данных третьим лицам

Разработчик не продаёт персональные данные пользователей.

Технические данные могут обрабатываться сторонними сервисами в объёме, необходимом для работы соответствующей функции приложения.

В частности, Yandex Mobile Ads SDK может обрабатывать технические и рекламные данные для показа рекламы, измерения эффективности, обеспечения безопасности рекламной системы и выполнения иных функций рекламной платформы.

Данные также могут быть предоставлены в случаях, предусмотренных применимым законодательством.

12. Аналитика

Разработчиком не внедрена отдельная система аналитики поведения пользователей для анализа игрового прогресса.

При этом рекламный SDK может самостоятельно обрабатывать технические данные и события, относящиеся к показам и взаимодействию с рекламой, в соответствии с правилами соответствующей рекламной платформы.

13. Срок хранения данных

Игровой прогресс и настройки хранятся локально на устройстве до их удаления пользователем, очистки данных приложения или удаления игры.

Сроки хранения технической информации, обрабатываемой сторонними рекламными сервисами, определяются соответствующими сервисами и их политиками конфиденциальности.

14. Удаление данных

Пользователь может удалить локальные данные игры:

  • очистив данные приложения в настройках Android;
  • удалив приложение с устройства.

После удаления локальных данных могут быть удалены игровой прогресс, настройки и другие сведения, сохранённые приложением на устройстве.

Данные, которые ранее могли быть обработаны сторонними сервисами, регулируются политиками соответствующих сервисов.

15. Защита данных

Для сетевых запросов приложение использует защищённые HTTPS-соединения.

Разработчик принимает разумные технические меры для ограничения несанкционированного доступа к информации, обрабатываемой приложением.

16. Дети и возрастные ограничения

Использование рекламных технологий может зависеть от возрастной категории приложения, требований магазина приложений и применимого законодательства.

Если для выбранной возрастной категории требуется использование неперсонализированной рекламы или дополнительные ограничения, соответствующие настройки рекламного SDK должны применяться разработчиком.

17. Управление своими данными

Пользователь может:

  • изменять игровые настройки;
  • удалять локальные данные игры;
  • изменять системные настройки рекламы Android;
  • ограничивать персонализацию рекламы средствами устройства;
  • обратиться к разработчику по вопросам обработки данных.

18. Изменения Политики

Настоящая Политика может обновляться при изменении функций игры, способов обработки данных, рекламных технологий, требований законодательства или магазинов приложений.

Актуальная редакция Политики публикуется на этой странице.
